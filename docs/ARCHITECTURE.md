# Architecture

React communicates with `/api` through the Vite proxy. MapLibre renders a blank background, GeoJSON boundaries, and a georeferenced image source from a bounded server preview. Original GeoTIFFs are never read wholesale into browser memory. Downloads use managed output identifiers.

`backend/models.py` contains explicit project, study area, grid, asset, validation, configuration, job, manifest, and output models. SQLite stores project state, asset declarations, and job snapshots. `backend/storage.py` is the local storage/database boundary; a remote store can replace managed-file access without accepting client paths. SQL files in `backend/migrations` run once via `schema_migrations`.

The worker atomically claims a queued job under an SQLite transaction. A local lock prevents competing workers. Each claimed job runs in a new process group and isolated `runs/<id>` directory. Progress/logs persist in SQLite; subprocess output goes to a downloadable log route. Cancellation kills that process group with a TERM/KILL grace period. Linux parent-death supervision terminates a child if the worker dies. Startup recovery marks running records interrupted. Result publication updates the manifest and success state only after output/package completion, and only while the record is still running. Failed/cancelled/interrupted artifacts remain private and unavailable through result routes.

A submitted snapshot includes assets, hashes, declarations, project geometry, and configuration. The runner checks source hashes before work. A stage key combines raster identifiers/checksums/roles, grid, stage version, and dependency versions; weather and thermal changes do not invalidate geometry. Cache files are published with atomic replacement. No weather calculation cache exists yet, and the demo does not consume weather values.

The shared adapter protocol has capabilities, input validation, preparation, execution, and output collection. `DemoAdapter` and `QgisUmepAdapter` are explicitly selected. The latter probes a separate QGIS interpreter, registers standard processing providers, and optionally loads a configured UMEP plugin. It cannot run a scientific job in this version. `LidarProcessor` publishes stages and an unsupported capability boundary. Additional model/acquisition adapters should use the same provenance, stage cache, managed storage, and job boundaries.

No source repair is performed. Future derived-asset preparation must record transformation CRS/datums, resampling, units, source hashes, and history. Categories use nearest-neighbour; continuous quantities may use documented bilinear resampling, without implying improved source accuracy. Unknown data must remain masked, while absent vegetation must be an explicit declaration.
